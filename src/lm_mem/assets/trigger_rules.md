## lm-mem 使用规则

跨会话记忆的**常驻触发规则** —— 只回答"何时该理会记忆"。怎么调工具、
去重 / 更新 / 冲突 / 作用域 / metadata / TTL,一律加载 SKILL.md 后按它执行
(Claude:`Skill(lm-mem:memory)`)。

**冷启动**:新会话首轮涉及代码 / 行为决策 → 先调一次 `get_user_context(user_id)`
把核心偏好吃进上下文;此后本会话不再逐轮检索,只在下面命中时才动。
`user_id` = `git config user.name`,取不到退回 `$USER`;全程只用这一个值。

**触发**(命中任一 → 理会记忆;要落库先加载 SKILL.md):
- 持久信息:"记住 / 我喜欢 / 我习惯 / 我总是 / 以后都这样"
- 指向过往:"我之前说过 / 还记得吗 / 按老规矩"
- 改口:"我改用 X 了 / 现在不用 Y 了" → **先确认再覆盖,别把过期事实留在库里**
- 要求增删改:"忘掉 / 删掉我说过的 X"
- 新话题或新项目要写改代码、而冷启动没覆盖到 → 补检索一次

**不触发**:纯技术问答、一次性指令("这次 / 仅本次")、用户说"不用记忆"。

**红线**(绝不入库):密钥与令牌、未脱敏 PII、第三方隐私、临时状态与情绪、
代码 / git log / CLAUDE.md 里本来就查得到的事实。

**落库时最容易漏的两条**(其余见 SKILL.md):
- 别只填 `user_id`:项目相关的事实**必须带** `app_id`
- 存储语言 = 用户当前对话语言
